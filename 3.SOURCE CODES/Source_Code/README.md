# 💻 Kaynak Kodlar (Source Code)

Bu dizin projenin üç ana bileşenini içerir:

1. **`backend-api/`**: Java 21 & Spring Boot 3.3 tabanlı RESTful API servisi (Port `8080`, Context Path `/api`).
2. **`ai-service/`**: Python FastAPI tabanlı Makine Öğrenmesi, ARIMA Tahminleme, Isolation Forest Anomali Tespiti ve Gemini Vision / EasyOCR Fiş Analiz servisi (Port `8000`).
3. **`mobile_app/`**: Flutter ile geliştirilmiş Android/iOS/Web/Masaüstü uyumlu kullanıcı uygulaması.

Detaylı kurulum ve mimari açıklamalar için ana dizindeki [README.md](../../README.md) dosyasına bakabilirsiniz.
